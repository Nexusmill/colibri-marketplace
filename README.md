# Colibri Marketplace

A Claude Code / Cowork plugin marketplace by Nexusmill.

## Plugins

### colibri-review

A rigorous, context-aware protocol for code review and debugging — one file at a time, repo
context assembled before judging, and every finding adversarially verified before it ships.
MIT licensed. See [`plugins/colibri-review`](./plugins/colibri-review).

## Install

Add this marketplace, then install the plugin:

```
/plugin marketplace add Nexusmill/colibri-marketplace
/plugin install colibri-review@colibri-marketplace
```
